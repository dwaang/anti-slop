# English AI Stop-Words and Clichés

## 1. High-Probability "AI Hallmark" Words
These words occur in LLM prose at rates orders of magnitude higher than human writing. Cut or replace with ordinary, specific words.

| Overused AI Word | Plain Human Replacement |
|---|---|
| Delve (into) | Look at, explore, examine, study, dig into |
| Tapestry (abstract) | Mix, collection, variety, history, system |
| Testament (stands as a) | Shows, proves, reflects, demonstrates |
| Crucial / Pivotal | Important, key, needed, decisive |
| Paramount | Main, urgent, critical |
| Intricate / Intricacies | Complex, detailed, nuances, parts |
| Dynamic | Active, changing, fast |
| Robust | Strong, reliable, solid, resilient (keep purely technical uses) |
| Landscape (abstract) | Field, market, industry, situation |
| Realm | Field, area, world, domain |
| Beacon | Example, guide, leader |
| Foster / Cultivate | Support, encourage, build, grow, help |
| Harness / Leverage | Use, apply, take advantage of |
| Spearhead | Lead, run, head |
| Bolster | Support, strengthen, back |
| Showcase | Show, display, feature |
| Revolutionize | Change, overhaul, transform |
| Navigate (challenges) | Handle, deal with, manage, solve |
| Streamline | Simplify, speed up, cut down |
| Unlock (potential) | Enable, achieve, open up |
| Elevate | Improve, raise, sharpen |
| Underscore / Highlight | Stress, emphasize, note |
| Meticulous / Meticulously | Careful, thorough, exact |
| Vibrant | Lively, active, colorful |
| Enduring | Lasting, long-standing |
| Interplay | Relationship, connection, interplay |

---

## 2. Throat-Clearing Openers (Cut outright)
These add zero information. Delete the phrase and begin directly with the point.

- "Here's the thing:"
- "Here's what [X] really means:"
- "Here's why this matters:"
- "The uncomfortable truth is"
- "It turns out that"
- "The truth is,"
- "Let me be clear:"
- "Make no mistake:"
- "At its core," / "Fundamentally,"
- "In today's fast-paced digital world,"
- "Without further ado,"
- "Now, let's dive into..."
- "Let's unpack this:"
- "Can we talk about..."
- "I'm going to be honest with you:"

---

## 3. Emphasis Crutches & Dramatic One-Liners (Cut or merge)
- "Full stop." / "Period."
- "Let that sink in."
- "Read that again."
- "And that changes everything."
- "That is the real win."
- "That distinction matters."
- "This cannot be overstated."

---

## 4. Corporate Jargon & Hollow Modifiers
| Avoid | Use Instead |
|---|---|
| Double down | Commit more, focus on |
| Deep dive | Detailed look, analysis |
| Take a step back | Reconsider, pause |
| Moving forward | Next, from now on |
| Circle back | Revisit, follow up |
| On the same page | Agreed, aligned |
| Seamless integration | Connects cleanly, works together |
| Game-changer | Major shift, big improvement |
| Cutting-edge / State-of-the-art | Modern, new, latest |
| Value proposition | Benefit, reason to buy |
| Synergies | Shared benefits, combined strengths |

---

## 5. Shallow -ing Participle Riders
Avoid bolting a superficial analytical clause onto a sentence:
- "..., thereby fostering a collaborative culture." -> State what happened directly.
- "..., highlighting the need for vigilance." -> State why it matters without the rider.
- "..., reflecting the company's commitment to quality." -> Cut the PR fluff.
